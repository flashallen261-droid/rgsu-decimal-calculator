# Decimal калькулятор

Самостоятельное выполнение практической работы №2.
Исходная версия `before.py` использует float; улучшенная `calculator.py`
использует Decimal, проверяет конечность значений, деление на ноль и операции.
Вычисления выполняются с точностью 28 значащих цифр; бесконечные дроби округляются.

Требуется Python 3.11 или новее. Внешние библиотеки не нужны.

```bash
python calculator.py 0.1 + 0.2
# 0.3
python calculator.py 10 / 4
# 2.5
python calculator.py 2 '*' 3
# 6
python calculator.py 1 / 0
# ошибка и код завершения 2
python -m unittest discover -v
```

Сравнение версий:

```bash
python before.py 0.1 + 0.2
# 0.30000000000000004
python calculator.py 0.1 + 0.2
# 0.3
```

При публикации этот репозиторий должен быть **public**. Команды публикации
находятся в корневом файле комплекта `PUBLISH_GITHUB.md`.
